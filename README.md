# 倫理審査申請書 事前チェックツール(ethics_form_checker)

早稲田大学の「人を対象とする研究に関する倫理審査申請書」(様式1〜4一体型、Ver.2.1)を対象に、公式の「よくある記載不備事例集」に載っている項目間の整合性ルールをコード化し、提出前にまとめてチェックできるようにしたツールです。

## これは何をするツールか

倫理審査申請書は、様式1〜4にまたがって同じ内容(所属・個人情報の扱い・同意の取り方など)を何度も書く必要があり、片方だけ修正して他方が古いままになる、といった食い違いが起こりやすい書類です。このツールは、そうした「よくある記載不備」のパターンを実際のExcelファイルに対して自動でチェックし、以下の3段階で結果を一覧表示します。

- **問題あり**:公式の不備事例集に照らして、明確に矛盾・記載漏れがある箇所
- **要確認**:自動では判断しきれないが、人の目で確認したほうがよい箇所
- **問題なし**:チェックした範囲で問題が見つからなかった箇所

Excelファイルに内蔵されている「管理用」シートの自動チェック(空欄チェック)を置き換えるものではなく、**それを補完するもの**です。両方を使うことを想定しています。

## なぜ作ったか

生成AI(ChatGPTなど)にチェックさせる方法も検討しましたが、この申請書には氏名・学籍番号などの個人情報が含まれるため、外部のサービスに内容を送信したくありませんでした。そこで、自分のパソコンの中だけで完結する独立したツールとして作成しました。

**このツールは、ファイルの中身を一切外部(インターネット上のサーバーやAIサービス)に送信しません。** すべての処理は、お使いのパソコンの中だけで完結します。

## 使い方

Python 3と、Excelファイルを読み書きするための`openpyxl`ライブラリが必要です。

```bash
pip install openpyxl
python3 ethics_form_checker.py 対象ファイル.xlsx
```

テンプレートのバージョン表記が、このツールが動作確認済みのバージョン(Ver.2.1)と異なる場合は、内容チェックの前に警告を出して停止します(セル位置がずれている可能性があり、結果が信用できないため)。バージョン確認をスキップして実行したい場合は、以下のように`--force`を付けてください(セル番地が実際とずれていても構わない場合のみ)。

```bash
python3 ethics_form_checker.py 対象ファイル.xlsx --force
```

## チェックしている内容(一部)

公式の記載不備事例集に基づき、以下のような項目間の整合性を確認します。

- 研究責任者・研究実施代表者の所属欄の書き方(学術院名のみか、学部・研究室名が混じっていないか)
- 研究実施期間が開始日から5年以内に収まっているか
- 研究区分によって公開データベースへの登録が必須になっていないか
- 企業等との関わりの有無と、経済的利益関係の記載が整合しているか
- 録画・録音を行う場合に、収集する個人情報の欄へ記載があるか
- データの保管期間が推奨される5年以上になっているか
- 募集要領の添付有無と、募集要領に関するチェック欄が整合しているか
- 文書によるインフォームド・コンセントを得る場合に、氏名の収集にチェックが入っているか
- 「個人情報を収集しない」と「匿名化する」という、両立しない選択が同時にされていないか
- 説明文書の問い合わせ先に、研究責任者の連絡先が記載されているか

## 制限事項・注意点

- このツールは、早稲田大学の公式テンプレート「人を対象とする研究に関する倫理審査申請書_Ver2.1.xlsx」の行・列構成が変わっていないことを前提にしています。テンプレートが改訂された場合や、行・列を挿入・削除した場合は、スクリプト内`CELLS`まわりのセル番地を実際のファイルに合わせて修正する必要があります。
- チェックしているのは、公式の記載不備事例集に基づく主要なルールのみです。これですべての記載不備を検出できるわけではありません。
- 早稲田大学以外の様式には、そのままでは対応していません。ただし、同じような「複数の様式にまたがる記載の整合性チェック」という考え方は、他大学の申請書にも応用できると考えています。
